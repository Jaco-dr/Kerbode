# Kerbode — vernieuwde bezorglijst

De lijst heeft een warme crème- en olijfgroene vormgeving, met het aangeleverde mozaïeklogo. Adressen staan in kolommen op desktop en in compacte kaarten op mobiel.

## Uploaden naar GitHub

Vervang in de bestaande repository `index.html`, `styles.css` en `script.js`, upload de map `assets` met `kerkbode-logo.png`, en laat je bestaande `adressen.js` staan. De `adressen.js` in dit pakket is een kopie van de oude repositoryversie en alleen bedoeld als herstelbestand als jouw repository die mist.

De bezorgcheckbox blijft altijd direct beschikbaar. Adressen beheren kan pas nadat je op **Bewerken** klikt. In die modus kies je met het pijltje bij een adres een invoegplek; een nieuw adres komt direct eronder. Zonder gekozen invoegplek komt het onderaan. Het potloodje opent adresbewerking. Verwijderen vraagt om bevestiging.

Adreswijzigingen en bezorgvinkjes worden alleen in de browser van de beheerder bewaard; ze synchroniseren niet tussen apparaten. De bewerkknop is een extra handeling tegen per ongeluk aanpassen, geen wachtwoordbeveiliging.
